  Trigger with: /simple-qa (takes no arguments)
  Use when the user wants short, plain answers, or says /simple-qa.

<overview>

Once invoked, answer every later question in the session in this style.

</overview>

<critical_rules>

- Use simple English.
- Define each new term first, then use that same term every time; never swap in a synonym.
- Answer in bullet points, so the answer is easy to scan.
- Write at most three bullets, each with few words, and make them read as one coherent answer.

</critical_rules>
